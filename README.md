# Legal Document Risk & Clause Extractor

Upload a contract (PDF, DOCX, PNG or JPG) and get a plain-language summary plus every important clause, quoted exactly as written and rated High, Medium or Low risk, with an explanation and a negotiation suggestion. Results can be shown in English or Burmese.

> This tool does not provide legal advice. The analysis is generated by AI and may contain mistakes.

## Stack

- `client/` — Vite, React, TypeScript, Tailwind
- `server/` — Express, TypeScript (run with tsx), Gemini API (`@google/genai`), zod

## How it works

1. The server extracts text from the upload (pdf-parse for PDF, mammoth for DOCX, Gemini OCR for images).
2. Gemini returns clauses through structured output (`responseSchema`), validated with zod.
3. Every quoted clause is checked against the document text; clauses whose quote cannot be found are dropped.
4. Files are held in memory only and are never written to disk.

## Setup

Requires Node.js 22 or newer.

```bash
# server
cd server
npm install
cp .env.example .env        # then put your Gemini API key in .env
npm run dev                 # http://localhost:3001

# client (second terminal)
cd client
npm install
npm run dev                 # http://localhost:5173
```

The client proxies `/api` to the server. `GEMINI_API_KEY` is read only by the server and must never be committed.

## Scripts

Run in `client/` and in `server/`:

- `npm run lint`
- `npm run build`

## Configuration (`server/.env`)

| Variable | Purpose | Default |
|---|---|---|
| `GEMINI_API_KEY` | Google AI Studio API key | required |
| `PORT` | Server port | `3001` |
| `GEMINI_MODEL` | Preferred model, tried first; lighter models are fallbacks when it is overloaded | `gemini-3.5-flash` |
| `ANALYZE_RATE_LIMIT` | Max `/api/analyze` requests per IP per 15 min | `10` |
| `TRANSLATE_RATE_LIMIT` | Max `/api/translate` requests per IP per 15 min | `30` |
